# RTL8211F management

`Livt.IO.Phy.Rtl8211Phy<PHY_ADDRESS = 1, POLL = 10ms>` implements
`IEthernetLinkStatus` using one borrowed `IMdioController`. It supports
100BASE-TX full duplex only. The integrating application supplies a stable reference clock,
hardware reset and `startupReady`; changing the `restart` toggle reinitializes
management without resetting unrelated application state. Its constructor is
`(mdio: IMdioController, startupReady: bool, restart: bool)`.
`PHY_ADDRESS` must be in 0..31 and `POLL` must be at least 1 us.

The manager validates PHY IDs, performs a bounded software reset, configures and
reads back RGMII RX-delay enable/TX-delay disable, advertises 100-full only,
disables gigabit/EEE advertisement and restarts negotiation. The external RGMII transmit path must
provide transmit clock/data skew. BMSR is read twice to clear latched link-down;
physical status is read on page `0x0A43`, register 26, then the page is restored.
`ready` requires completed negotiation and actual 100-full link status.

MDIO has one owner: do not call the borrowed controller concurrently. Reads and
writes are scheduled. The manager continuously polls; loss of startup readiness
or a restart immediately suppresses `ready`, while detected link loss or failed
management suppresses it on the next status check. Failed configuration retries
after `POLL`. Reset invalidates readiness and restarts initialization. Diagnostic
outputs are snapshots, not a transactionally consistent register dump.

The implementation stores only register/status words, counters and state; it
has no packet arrays or RAM and shares the serialized MDIO engine. Polling is
bounded by `POLL` plus the scheduled management transactions. A reset which
never clears is bounded by 10,001 register reads before retry.

The component manages PHY registers and link status only. RGMII serialization,
clock-domain crossings, pad drivers and interface timing constraints are supplied
by the integrating application. The configured PHY delay settings must match
that application's clock/data timing.
